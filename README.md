# Бот учёта 3D-пластика и расчёта себестоимости печати

Telegram-бот на Python: учёт катушек филамента, расчёт себестоимости печати,
редактирование карточек, уведомления о низком остатке и импорт из Excel.

## Стек

- **Python + aiogram 3** — асинхронный фреймворк для Telegram-ботов.
- **PostgreSQL (Supabase)** через `asyncpg` — хранение катушек. Таблица и
  миграции применяются автоматически при каждом запуске.
- **openpyxl** — разбор Excel-файлов при импорте.
- **aiohttp** (идёт вместе с aiogram) — минимальный HTTP-эндпоинт `/` для
  проверки «здоровья» сервиса на бесплатном хостинге.

## Быстрый локальный запуск

1. Получите токен у [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Узнайте свой Telegram ID у [@userinfobot](https://t.me/userinfobot).
3. `pip install -r requirements.txt` (нужен Python 3.10+).
4. Скопируйте `.env.example` → `.env`, заполните `BOT_TOKEN`, `WHITELIST` и
   `DATABASE_URL` (строка подключения к Supabase — см. `DEPLOY.md`, шаг 1).
5. `python bot.py`.

## Продакшн-развёртывание (Render + Supabase + UptimeRobot)

Полная пошаговая инструкция под вашу связку хостинга — в **`DEPLOY.md`**.

## Возможности

### Основное (по исходному ТЗ)
Разграничение доступа по белому списку · просмотр остатков · пошаговый
мастер добавления катушки · ручное списание · расчёт себестоимости с
автосписанием в один клик.

### Добавлено дополнительно
- **Быстрые кнопки по истории.** На шагах бренда/типа/цвета/температур бот
  подставляет недавно использованные значения из базы вместо статичного
  списка — заполнение ускоряется по мере накопления данных. Пока истории
  нет, показываются стандартные варианты (константы в начале
  `handlers/add_spool.py`).
- **До 3 фото на катушку.** И при добавлении, и при редактировании.
- **Редактирование карточек.** На детальной карточке (кнопка «Показать» в
  списке остатков) появилась кнопка «✏️ Редактировать» — можно изменить
  любое поле или управлять фото (добавить/очистить).
- **Архив использованных катушек.** Катушка с остатком 0 г не удаляется и
  не пропадает — она просто уходит из активного списка и доступна через
  кнопку «📦 Архив» внизу «Остатков». Если остаток отредактировать обратно
  выше 0, катушка автоматически возвращается в активный список — отдельного
  флага «архивная» в базе нет, всё определяется по остатку.
- **Уведомление о низком остатке.** Как только остаток катушки при
  списании опускается до 500 г и ниже, всем пользователям из `WHITELIST`
  приходит сообщение. Порог настраивается переменной окружения
  `LOW_STOCK_THRESHOLD_G` (без изменения кода). В списке и в детальной
  карточке такие катушки дополнительно помечены ⚠️.
- **Импорт из Excel.** Пришлите боту `.xlsx`-файл в любой момент — он
  разберёт его и предложит подтвердить импорт. Подробности и формат
  колонок — раздел ниже.
- **Быстрые действия с карточки.** На детальной карточке катушки — кнопки
  «➖ Списать» и «🧮 Рассчитать» (для активных катушек), сразу переходящие к
  нужному сценарию для этой катушки, без повторного выбора из списка.
- **Сортировка по остатку.** Список «Остатки» показывает катушки в порядке
  от самых заканчивающихся — не нужно искать их вручную.
- **Сводка по складу.** Кнопка «📊 Сводка по складу» внизу «Остатков» —
  общий вес, примерная стоимость запасов (по той же логике, что и расчёт
  себестоимости) и разбивка по типам пластика.
- **История операций.** Кнопка «📜 История» на карточке показывает последние
  действия по этой катушке: кто добавил, списывал, редактировал — с датой,
  автором и значениями «было → стало».
- **Экспорт в Excel (`/export`).** Выгружает все катушки (активные и архив)
  в файл с теми же колонками, что понимает импорт — это одновременно отчёт
  и резервная копия. Фото не восстанавливаются автоматически, но их ID
  сохраняются в отдельной колонке на случай ручного восстановления.

## Импорт из Excel

Пришлите файл `.xlsx` прямо в чат с ботом (как документ, не как фото) —
он сработает независимо от того, чем вы в этот момент занимались в боте.

Бот ищет заголовки колонок (регистр не важен, порядок любой, лишние
колонки игнорируются):

| Поле                | Подходящие заголовки                                 | Обязательно |
|---------------------|-------------------------------------------------------|:-----------:|
| Бренд               | Бренд, Производитель, Марка                            | да |
| Тип пластика        | Тип, Тип пластика, Материал                             | да |
| Цвет                | Цвет                                                     | да |
| Остаток             | Остаток, Остаток (г), Вес, Вес (г), Масса, Масса (г)      | да |
| Темп. сопла         | Темп. сопла, Температура сопла, Сопло                     | нет |
| Темп. стола         | Темп. стола, Температура стола, Стол                       | нет |
| Цена                | Цена, Стоимость, Цена (руб)                                  | нет |

Числа принимаются и с точкой, и с запятой. Пустые строки пропускаются;
строки без обязательных полей — тоже, с пояснением, какая строка и
почему пропущена, до подтверждения импорта.

**Фото при импорте не переносятся** (в самих данных их обычно и нет) —
после импорта откройте нужную катушку через «Остатки» → карточка →
«✏️ Редактировать» → «Фото», чтобы прикрепить снимки.

Если заголовки в вашей таблице называются иначе — либо переименуйте их
перед загрузкой под таблицу выше, либо пришлите файл (или список ваших
заголовков) и попросите подстроить список синонимов в `excel_import.py`
под вашу таблицу.

├── keyboards.py                     # клавиатуры: меню, выбор, списки катушек

├── excel_import.py                           # разбор Excel для импорта
├── render.yaml                                 # опциональный Render Blueprint
├── DEPLOY.md                                      # инструкция по деплою
├── handlers/
│   ├── common.py            # /start, /cancel, меню
│   ├── view.py                # просмотр остатков, детальная карточка
│   ├── add_spool.py             # мастер добавления
│   ├── writeoff.py                # ручное списание

## Что легко поменять под себя

- **Списки быстрых кнопок по умолчанию** (пока нет истории) — константы
  в начале `handlers/add_spool.py`.
- **Формула себестоимости и тарифы** — константы в начале
  `handlers/calculate.py`.
- **Порог низкого остатка** — переменная окружения `LOW_STOCK_THRESHOLD_G`
  (по умолчанию 500).
- **Синонимы заголовков для импорта** — словарь `COLUMN_ALIASES` в
  `excel_import.py`.
- **Доступ** — список ID меняется в `WHITELIST` без изменения кода
  (после правки нужен рестарт сервиса). Из них через `ADMIN_IDS` можно
  назначить администраторов: только они видят и могут использовать
  «✏️ Редактировать» на карточке (изменение полей, управление фото).
  Остальные из `WHITELIST` — смотрят, добавляют, списывают, считают
  себестоимость и делают `/export`, но не редактируют существующие карточки.

## Ограничение

Незавершённый сценарий (мастер добавления, редактирование, импорт)
хранится в памяти процесса. Если сервис перезапустится посреди
ввода — шаг придётся начать заново; на уже сохранённых в Supabase
катушках это не сказывается.

## Возможные доработки
